flex - властивість

CSS властивість flex задає "еластичність" (або вагу) елементу. Еластичні елементи витягуються, займаючи весь відведений для нього простір. Але елементи з різною вагою займають різну долю загального вільного простору (пропорційно до ваги)

Картки та макети

Картка

Картка (card) - один з центральних термінів веб-дизайну. Широко використовується для представлення різноманітних сутностей:товар, фильмів, ігор тощо.

Анатомія картки взята з цього сайту: https://m3.material.io/components

Часникодавка
Зручність на кожній кухні.
Практична часникодавка допоможе швидко подрібнити часник без зайвих зусиль. Міцна конструкція, зручна ручка та легке очищення роблять її незамінним помічником під час приготування улюблених страв.
