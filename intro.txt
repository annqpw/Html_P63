Вступ до HTML
HTML - HyperText Markup Language - Гіпертекстова мова розмітки
Гіпертекст - текст із включенням фрагментів, які сприймаються
в якості керуючих елементів (програмного коду)

git config --global user.name "annqpw_12"
git config --global user.email "evelonn@gmail.com"

Commit - певне збреження, необхідно ввести повідомлення (назву)
Push - передати в коміт (коміти) до віддаленого сховища (ГітХаб)
Pull - "витягнути" коміти з відаленного сховища до локального проєкту
Sync - синхронізуватись (витягнути та передати) 
Clone - створення локального проєкту з відаленного репозиторію  (сховища)
Publish - створення віддаленого репозиторію з локального проєкту 
(public - загальнодоступний, private - прихований для інших)
