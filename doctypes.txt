Витяг про типи (версії) HTML у тегу <!DOCTYPE>
<!DOCTYPE> — це оголошення типу документа, яке повідомляє браузеру, за яким стандартом потрібно обробляти HTML-документ.
HTML 2.0: <!DOCTYPE HTML PUBLIC "-//IETF//DTD HTML 2.0//EN">
HTML 3.2: <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 3.2 Final//EN">- HTML 4.01 Strict: <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN" "http://www.w3.org/TR/html4/strict.dtd">
HTML 4.01 Transitional: <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN" "http://www.w3.org/TR/html4/loose.dtd">
XHTML 1.0: мав кілька варіантів оголошення: Strict, Transitional і Frameset.
HTML5: <!DOCTYPE html>
Висновок: для сучасних HTML-документів використовують <!DOCTYPE html>. Він забезпечує стандартний режим відображення сторінки в браузері.
