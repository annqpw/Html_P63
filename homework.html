Шістнадцяткова система числення та RGB

Як комп'ютер кодує кольори за допомогою чисел?

1. Що таке шістнадцяткова система числення?

Шістнадцяткова система числення — це система, у якій використовуються 16 символів: цифри від 0 до 9 та літери від A до F. Вона широко застосовується в програмуванні для запису кольорів, адрес пам'яті та інших даних.

  • F = 15

2. Що таке RGB?

RGB — це колірна модель, назва якої утворена від трьох англійських слів:

R — Red

Червоний

255, 0, 0

G — Green

Зелений

0, 255, 0

B — Blue

Синій

0, 0, 255

Кожен колір формується змішуванням червоного, зеленого та синього світла. Для кожного компонента використовують значення від 0 до 255.

  • 0 — компонент відсутній.
  • 255 — максимальна інтенсивність компонента.
Основні приклади RGB:

Чорний: rgb(0, 0, 0)

Білий: rgb(255, 255, 255)

Жовтий: rgb(255, 255, 0)

Блакитний: rgb(0, 255, 255)

Пурпуровий: rgb(255, 0, 255)

3. Як утворюється шістнадцятковий код кольору?

У HTML і CSS кольори часто записують за допомогою шістнадцяткового коду. Він починається символом # і містить шість символів.

#RRGGBB

  • RR — інтенсивність червоного.
  • GG — інтенсивність зеленого.
  • BB — інтенсивність синього.

Кожна пара символів задає значення одного компонента від 00 до FF, тобто від 0 до 255.

Колір RGB HEX
Чорний 0, 0, 0 #000000
Білий 255, 255, 255 #FFFFFF
Червоний 255, 0, 0 #FF0000
Зелений 0, 255, 0 #00FF00
Синій 0, 0, 255 #0000FF
Жовтий 255, 255, 0 #FFFF00
Помаранчевий 255, 128, 0 #FF8000

Приклад: #FF8000

FF = 255 — червоний компонент.

80 = 128 — зелений компонент.

00 = 0 — синій компонент.

Результат — помаранчевий колір.

4. Як перевести HEX у десяткову систему?

Щоб перевести двоцифрове шістнадцяткове число в десяткове, першу цифру потрібно помножити на 16, а потім додати значення другої цифри.

Приклад: 80

80₁₆ = 8 × 16 + 0 = 128₁₀

Приклад: FF

FF₁₆ = 15 × 16 + 15 = 255₁₀

Отже, код #FF8000 відповідає значенням RGB (255, 128, 0).

5. Де використовують RGB і HEX?

  • Під час створення сайтів за допомогою HTML і CSS.
  • У графічних редакторах для вибору кольорів.
  • У комп'ютерній графіці та вебдизайні.
  • Під час розроблення ігор та інтерфейсів програм.
Запам'ятай! RGB задає інтенсивність трьох кольорів числами від 0 до 255, а HEX записує ті самі значення у шістнадцятковій системі двома символами для кожного компонента.

Висновок

Шістнадцяткова система числення дає змогу компактно записувати числові значення. Модель RGB використовує червоний, зелений і синій компоненти для створення різноманітних кольорів. Разом вони є важливою основою комп'ютерної графіки та оформлення вебсторінок.
